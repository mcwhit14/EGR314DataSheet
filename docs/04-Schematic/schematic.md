## Overview

This schematic shows the 9V input being stepped down to 3.3V. The ESP32 reads distance measurements from the ToF sensor over I2C. The Distance data is transmitted to the motor subsystem via UART. Debug LEDs on board and external to provide visual status and proximity feedback. This Design allows the subsystem to function independently while communicating critical obstacle detection data to the rovers's main control system.
