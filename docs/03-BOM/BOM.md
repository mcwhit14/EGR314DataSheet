## Overview
The Bill of Materials (BOM) lists all components required to implement this subsystem of the project. It includes the main controller (ESP32 development board), power regulation components for generating a stable 3.3 V supply, passive components for filtering and signal conditioning, protection devices such as resettable fuses, interface connectors, and the Time-of-Flight (ToF) distance sensor used for measurement. Each component entry includes manufacturer information, part numbers, supplier links, datasheets, and schematic reference designators to ensure traceability between the schematic design and purchased hardware. This BOM supports both prototyping and potential production by estimating component costs and ensuring that all required hardware can be sourced reliably.
